# (1NZ-FE) Yaris Reverse Engineering
Reverse Engineering focused on the 1NZ-FE Platform for 2nd gen Yaris/Vitz.
My main focus is for this platform to be accesible in a plug and play fashion for the Rusefi Platform. I don't have a junker car or most parts to physically bench test, but I'll do my best to keep it updated as I make any progress on the project at all if any.
